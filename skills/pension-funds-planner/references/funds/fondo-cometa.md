# Fondo Cometa reference

## When to use this file

Use this reference when the user names `Fondo Cometa` or `Cometa`.

## Fund-specific defaults to verify

These are practical planning defaults, not permanent truths. Confirm them before recommending an exact rate.

- Contribution-change requests are often handled with a `31 May` deadline for effectiveness from `1 July`.
- A later change window is often handled with a `30 November` deadline for effectiveness from `1 January` of the following year.
- The minimum employee contribution needed to preserve the employer contribution is often treated as `1.2%`.
- The employer contribution may be calculated on a narrower contractual base instead of the employee's full actual gross salary.

## Operational caveats

- A bonus or `variabile` paid in the following year usually affects Fondo Cometa contributions in that following year.
- Salary increases and retroactive payroll adjustments can create unexpected contribution spikes.
- If the `tredicesima` is contributable in the user's setup, December can create an extra contribution jump.
- When actual payroll amounts disagree with a simple percentage-of-RAL estimate, trust the payroll evidence first.

## What to confirm before recommending a rate

1. The current year's deductible cap.
2. The exact minimum rate needed to keep the employer contribution in the user's payroll setup.
3. The real contribution-change deadlines and effective dates for the employer and payroll system involved.
4. The actual payroll base used for the employer contribution.
5. Whether bonus, retroactive pay, and `tredicesima` follow the same contribution rate and hit the current year or the next one.

## Coverage note

This is a starter reference meant to make the planner useful immediately while leaving room for more precise Fondo Cometa documentation later.
