# Fund reference template

## When to use this file

- fund name
- aliases
- any contract or sector context that helps identify the fund

## Fund-specific defaults to verify

- contribution-change deadlines
- effective dates
- minimum employee rate needed to keep employer contribution
- employer-contribution formula or payroll base

## Operational caveats

- how bonuses or variable pay usually affect the fund
- whether retroactive pay is relevant
- whether `tredicesima` is usually contributable
- any known administration or payroll quirks

## What to confirm before recommending a rate

1. exact current-year deductible cap if the user has not provided it
2. exact employer-match threshold
3. exact change window and effective date
4. actual contribution base used by payroll
5. any special handling for bonus or extra payroll items

State whether the reference is detailed, partial, or only a starter reference.
