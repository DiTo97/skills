# skills

DiTo97's directory of high-quality standalone skills and plugins for Claude Code.

## Repository layout

- `skills/` contains standalone skills you can copy into `~/.claude/skills/` or `<project>/.claude/skills/`.
- `plugins/` contains plugin packages and related assets intended for the Claude Code plugin ecosystem.

## Standalone skills

Install a standalone skill by copying its folder into one of these locations:

- Personal install: `~/.claude/skills/<skill-name>/`
- Project install: `<project>/.claude/skills/<skill-name>/`

Current standalone skills:

- `italy-pension-funds-planner` — Italy-only pension-fund contribution planning with shared rules and per-fund references.

## Plugins

Current plugins:

- `ralph-loop-windows` — Windows-native PowerShell 7+ fork of Ralph Wiggum loop for Claude Code.
